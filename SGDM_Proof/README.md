# SGDM_Proof — Convergence of Stochastic Gradient Descent with Momentum

A self-contained, fully detailed proof that **stochastic gradient descent with momentum**
(SGDM, also called the stochastic heavy-ball method) converges. The proof is written in the
style of the standard *expected function value decrease* analysis of plain SGD. The report
also maps out **under what circumstances** convergence holds, and what goes wrong when it
does not.

**Report:** [`SGDM_Convergence_Report.pdf`](SGDM_Convergence_Report.pdf). It is
written for readers with a college background in calculus, linear algebra and probability.
Every step of every proof is written out.

## The idea in three steps

SGDM (heavy-ball form), with step size $\alpha>0$ and momentum $\beta\in[0,1)$:

$$x_{k+1}=x_k-\alpha\,g_k+\beta\,(x_k-x_{k-1}),\qquad \mathbb E[g_k\mid\text{past}]=\nabla f(x_k).$$

For SGD, every proof rests on the one-step inequality
$\mathbb E[f(x_{k+1})\mid\text{past}]\le f(x_k)-\tfrac{\alpha}{2}\Vert \nabla f(x_k)\Vert^2+\tfrac{L\alpha^2}{2}\sigma^2$.
For SGDM this inequality is **false**: momentum makes the iterates overshoot, so $f(x_k)$ can
go up even without noise. The fix:

1. **The extrapolated points do SGD.** Let $z_k=x_k+\frac{\beta}{1-\beta}(x_k-x_{k-1})$.
   This is where the "ball" would come to rest if all forces were switched off. Then
   $z_{k+1}=z_k-\gamma\,g_k$ exactly, with the **effective step size** $\gamma=\alpha/(1-\beta)$.
2. **A potential decreases in expectation, exactly as $f$ does for SGD.** With
   $\Phi_k=f(z_k)-f^\star+\frac{L\beta^2}{2(1-\beta)^2}\Vert x_k-x_{k-1}\Vert^2$,

   $$\mathbb E[\Phi_{k+1}\mid\text{past}]\le\Phi_k-\frac{\gamma}{4}\Vert \nabla f(x_k)\Vert^2+L\gamma^2\sigma^2
   \qquad\text{whenever}\qquad \alpha\le\frac{(1-\beta)^2}{2L}.$$

   In words, friction must dissipate kinetic energy faster than evaluating the gradient at
   $x_k$ instead of $z_k$ creates error.
3. **Everything else follows as for SGD.** Telescoping gives the guarantees below.

## What is proved

| Setting | Step-size condition | Guarantee |
|---|---|---|
| Nonconvex, $L$-smooth | $\alpha\le\frac{(1-\beta)^2}{2L}$ | $\frac1K\sum_{k<K}\mathbb E\Vert \nabla f(x_k)\Vert^2\le\frac{4\Delta}{\gamma K}+4L\gamma\sigma^2$ |
| Nonconvex, tuned $\gamma$ | $\gamma\propto 1/\sqrt K$ | $O\big(\frac{L\Delta}{(1-\beta)K}+\sigma\sqrt{L\Delta/K}\big)$, the same leading term as SGD |
| Nonconvex, decaying steps | $\sum\gamma_k=\infty,\ \sum\gamma_k^2<\infty$ | $\liminf_k\Vert \nabla f(x_k)\Vert =0$ almost surely |
| Exact gradients | $\alpha<\frac{2(1-\beta)}{L}$ | $\nabla f(x_k)\to0$ (mechanical energy decreases) |
| PL inequality | $\alpha\le\frac{(1-\beta)^2}{2L}$ | $\mathbb E f(x_k)-f^\star\le2(1-\frac{\gamma\mu}{4})^k\Delta+\frac{8L\gamma\sigma^2}{\mu}$ |
| PL, decaying steps | $\gamma_k=\frac{8}{\mu(k+a)}$ | $\mathbb E f(x_k)-f^\star=O(1/k)$ |
| Convex | $\alpha\le\frac{1-\beta}{2L}$ | $\mathbb E f(\bar x_K)-f^\star\le\frac{\Vert x_0-x^\star\Vert^2}{\gamma K}+\frac{2\beta\Delta}{(1-\beta)K}+\gamma\sigma^2$ |

Here $\Delta=f(x_0)-f^\star$ and $\gamma=\alpha/(1-\beta)$.

## Under what circumstances? (Section 7 of the report)

- **Friction is necessary.** You need $\beta<1$. With $\beta\ge1$ heavy ball does not
  converge even on $x^2/2$.
- **Think in effective step sizes.** The thresholds are $\gamma\le\frac{1-\beta}{2L}$ for
  nonconvex stochastic problems, $\gamma\le\frac1{2L}$ for convex ones, and
  $\gamma<\frac2L$ with exact gradients.
- **A constant step leaves a noise floor** of order $\gamma\sigma^2$. This cannot be avoided:
  it is computed *exactly* on quadratics. At equal $\gamma$ it is the same for SGD and SGDM.
  To converge exactly, decay the step size.
- **Too large a step diverges.** On quadratics the exact stability region is
  $\alpha L<2(1+\beta)$.
- **Quadratic intuition can mislead.** Polyak's quadratic-optimal parameters make heavy ball
  cycle on a smooth, strongly convex function (Lessard–Recht–Packard). The report verifies
  the 3-cycle by hand, in exact fractions.
- **No worst-case acceleration.** At equal effective step size, SGDM behaves like SGD.

## Repository layout

```
SGDM_Convergence_Report.pdf   the report (built from report/)
report/
  main.tex                    preamble, title, abstract
  sections/*.tex              one file per section (+ appendix, references)
  figures/*.pdf               figures generated by experiments/
experiments/
  common.py                   test problems + the SGDM (heavy-ball) iteration
  potential.py                f(x_k) oscillates, the potential Phi_k decreases
  regions.py                  admissible (alpha, beta) regions for each guarantee
  sgd_vs_sgdm.py              SGD vs SGDM at equal effective / equal raw step size
  noise_floor.py              noise floor ~ gamma * sigma^2 (exact formula vs simulation)
  diminishing.py              decaying step sizes remove the noise floor
  counterexample.py           the Lessard-Recht-Packard 3-cycle (verified exactly)
  run_all.py                  regenerate every figure
Makefile
```

## Building

```bash
pip install -r experiments/requirements.txt   # numpy, matplotlib
make figures      # rerun all experiments (about 2-3 minutes)
make              # build the PDF with latexmk -> SGDM_Convergence_Report.pdf
```

Building the PDF needs a TeX distribution with `latexmk`, `amsmath`, `tcolorbox`,
`cleveref` and `lmodern` (e.g. TeX Live). All random seeds are fixed, so the figures are
reproducible.
